# Global Codex Instructions

## 環境・依存関係
- このdotfilesは複数の端末で動作することを前提とする
- 新しいファイルや設定を追加する際は、必要な依存ツールをREADME.mdに明記する
- シェルスクリプトは `#!/bin/bash` を使い、bashが入っていれば動くように書く
- パスはなるべく `$HOME` を使い、ユーザー名入りのパスのハードコードを避ける

## コマンド実行
- `rtk` が入っている端末では、出力の多いコマンド（`git`, `ls`, `grep`, テストなど）は `rtk <cmd>` 経由で実行してトークンを節約する

## Git & Version Control
- Gitリポジトリをセットアップする際は、HTTPSよりSSH認証を優先する
- コミット前に変更内容を確認し、意図しないファイルが含まれていないか確認する

## Python Development
- Pythonプロジェクトの依存関係管理とパッケージングには `uv` を使う
- 仮想環境は `uv venv` で作成し、`uv pip` でパッケージをインストールする

## Workflow Preferences
- リファクタリングについて質問されたら、オプションを提示する前に完全な分析を完了する
- 調査を途中で終わらせない
- タスクの完了条件を明確にしてから作業を開始する
- 指示が不明瞭な場合は作業を始める前に質問して明確にする
