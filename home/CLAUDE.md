# Global Claude Code Settings

## 環境・依存関係
- このdotfilesは複数の端末で動作することを前提とする
- 新しいファイルや設定を追加する際は、必要な依存ツールをREADME.mdに明記する
- 依存ツール: `jq`（statusline.sh必須）、`rtk`（Claude Codeフック）
- シェルスクリプトは `#!/bin/bash` を使い、bashが入っていれば動くように書く
- パスはなるべく `$HOME` を使い、`/home/shiru` のようなハードコードを避ける

## Git & Version Control
- Gitリポジトリをセットアップする際は、認証の問題を避けるためHTTPSよりSSH認証を優先してください
- コミット前に変更内容を確認し、意図しないファイルが含まれていないか確認する

## Python Development
- このワークスペースのPythonプロジェクトでは、依存関係管理とパッケージングに `uv` を使用してください
- 仮想環境は `uv venv` で作成し、`uv pip` でパッケージをインストール

## Workflow Preferences
- リファクタリングについて質問されたら、オプションを提示する前に完全な分析を完了してください
- 調査を途中で終わらせないでください
- タスクの完了条件を明確にしてから作業を開始する
- 指示が不明瞭な場合は作業を始める前に質問して明確にする

## Available Custom Skills
- `/doc` - ドキュメント生成（目的、コンポーネント、使用例、依存関係を含む）
- `/refactor` - リファクタリング分析（重複、複雑性、命名、構造を分析）
